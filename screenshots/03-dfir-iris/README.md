# Phase 3 — AI-Assisted Triage

## Goal

Produce a consistent report from the alert and enrichment supplied by n8n without inventing evidence.

## Required Output

- Alert summary
- Severity and confidence
- Evidence-based findings
- MITRE ATT&CK mapping with justification
- Enrichment results
- Recommended investigation steps
- Escalation recommendation
- Explicit evidence gaps

The response must pass the JSON schema before downstream notification or case creation.
