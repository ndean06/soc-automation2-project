# Screenshot Evidence

Use lowercase filenames, hyphens, and a two-digit sequence number:

```text
[number]-[phase]-[tool]-[evidence].png
```

Examples:

```text
01-detection-splunk-sysmon-ingestion.png
02-detection-splunk-shadow-copy-results.png
03-orchestration-n8n-webhook-execution.png
04-ai-openai-structured-triage.png
05-notification-slack-alert.png
06-mcp-claude-splunk-tools-connected.png
```

Before committing, verify that each screenshot excludes credentials, API keys, tokens, complete webhook URLs, session data, and unnecessary personal information.
